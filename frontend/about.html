About Swatchfin

How Swatchfin reads a brand

Swatchfin turns a company name or a URL into a brand guide by reading the live website with three TinyFish APIs. This page explains what each one does, how the result is checked, and where the limits are.

  • 3 TinyFish APIs, each with one job: Search, Fetch and Browser
  • 10 pages read at most: the homepage and up to nine more
  • 1 short browser session per guide, always closed
  • 0 guesses: anything not found stays empty, with a warning

How TinyFish is used

Three TinyFish APIs, three different jobs

Each API does something the others can’t, so none of them is there for show. Every call is counted and listed in the guide’s Sources.

TinyFish Search

Find the official site

When you type a company name, Swatchfin searches for it and takes the first result on the brand’s own domain. Wikipedia, social networks, app stores and news sites are skipped, because they write about the brand rather than speak for it.

When you paste a URL, there is nothing to find, so Swatchfin uses your address and skips this step. Search can also look for a brand-guidelines or press-kit page to add to the pages read in step 4.

Per guide: one or two searches, none when you give a URL.

TinyFish Fetch

Read the live pages

Fetch does the core reading, in two requests. The first reads the homepage as HTML with ttl set to 0, which asks for a live copy rather than a cached one. Swatchfin parses that HTML for the logo (an image or inline SVG in the header, then the Open Graph image and the icons), the theme colour, the description and the site’s own navigation and footer links.

The second reads up to nine of those pages in one batch, as markdown: the page’s text without menus, scripts or styling. That text is what the tone of voice is drafted from, and what every quote is checked against. Fetch doesn’t return images, so the logo’s address always comes from the HTML.

Per guide: up to 10 URLs.

TinyFish Browser

Measure the real styles

A site’s stylesheet isn’t its palette: most rules never apply, and the final colours come from variables, themes and scripts. So Swatchfin opens the homepage in a TinyFish Browser session, a real browser in the cloud, and reads the computed style of what people actually see: body text, headings, links, navigation, header, footer and the main buttons.

Each colour is weighted by how important its element is and how much of the screen it covers, which decides its role: primary, background, text and so on. The fonts come from the ones the page really loaded. The same session confirms which image is the logo and how large it shows.

Per guide: one session, closed as soon as the styles are read, even when something goes wrong.

Checks

How a guide stays honest

A language model is good at describing a voice and bad at admitting what it doesn’t know. These checks keep its output tied to what the site really says.

Every quote is found word for word

Each tone trait, tagline, mission and value proposition comes with an exact quote and the page it’s from. Swatchfin then looks for that quote in the text it fetched, allowing only for differences in spacing and quote marks. A quote that isn’t there is dropped, and the guide says so.

Gaps stay empty

If a logo, colour, font or message can’t be found, its field is left empty and a warning explains why. A partial guide is labelled as partial. Swatchfin never fills a gap with a plausible guess.

Measured, then scored

Contrast is calculated with the WCAG 2.2 formula from the measured colours, and graded AA or AAA. Colours, fonts and the logo each get a confidence score that reflects how they were found.

Every source is listed

The guide lists every page it read, which TinyFish API read it and when, and how many calls each API made. You can open any page and check a quote yourself.

Output

Structured for other tools, not only for reading

Every guide is a JSON document with a versioned schema, so design tools, code and AI agents can use it directly.

  • Colours with their role, where they’re used, their share of the page and a confidence score.
  • Fonts with their weights, sizes and a fallback stack.
  • Tone traits and key messages, each with its quote, source page and a “verified” flag.
  • Exports as CSS custom properties, a Tailwind theme, W3C Design Tokens and a ready-to-paste voice prompt.

Limitations

What Swatchfin can’t see

A guide is a careful reading of a public website on one day. These are the places where that reading falls short.

  • Some sites turn away automated visits. If the homepage can’t be read at all, there is no guide; if one page is blocked, it is skipped and named in the warnings.
  • Pages behind a login, a paywall or a cookie wall can’t be read.
  • Colours and fonts are measured on the homepage only, at one screen size and in its default theme. The browser visits from the United States, so a site that changes by country shows its US version.
  • Colours inside photos, videos, gradients and illustrations aren’t measured, only the colours of page elements.
  • A logo drawn in CSS or set as a background image can be missed. The guide then falls back to the Open Graph image or the favicon, and says which one it used.
  • Fonts are named as the site loads them, but a specimen can only show a font that Google Fonts offers. Other fonts are shown in a fallback font, and the guide says so.
  • The tone of voice is a language model’s reading of the text. Its quotes are verified; its judgement, such as the traits and the tone scales, is an interpretation.
  • A guide is a snapshot. When the site changes, generate a new one.

Privacy

What is sent where

Swatchfin reads public websites. It doesn’t need anything about you to do that.

  • The name or URL you type is sent to TinyFish, which searches for the site and reads its public pages.
  • The text of those pages is sent to Anthropic’s Claude API, the language model that drafts the tone of voice and messaging.
  • Swatchfin never logs in to a site, fills in its forms or reads anything that isn’t public.
  • Each guide is kept on the Swatchfin server for a limited time, so its link keeps working. It contains only what the website shows publicly.
  • There are no accounts, no cookies and no analytics. Your light or dark theme choice is saved in your own browser and never sent anywhere.
  • Your browser loads the interface fonts from Google Fonts and the Bootstrap stylesheet from jsDelivr. A guide may also load a brand’s font from Google Fonts to show its specimen.
  • Brand names, logos and text in a guide belong to their owners. Swatchfin shows them to describe the brand, not to grant any right to use them.

The project

Built for the TinyFish Student Bounty

Swatchfin is an independent project by Ankan Chowdhury, built for the TinyFish Student Bounty Drop 001, “Brand Guide Generator”. It is not an official TinyFish product.

The code is open source under the MIT licence on GitHub. The TinyFish APIs are documented at docs.tinyfish.ai.

Icons are from Lucide (ISC licence). The interface uses Inter, Inter Tight and JetBrains Mono (SIL Open Font Licence).
