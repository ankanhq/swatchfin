Built on TinyFish Search, Fetch and Browser

Turn any website into a brand guide.

Type a company name or paste a URL. Swatchfin reads the live site with TinyFish and returns its logo, colours, fonts, tone of voice and key messages, each traced back to its source.

Only public pages are read. A guide takes about a minute.

How it works

Three TinyFish APIs read the site. Swatchfin checks the result.

Every guide is built from the live website, not from a saved screenshot or a guess. Each step has one job.

  1. TinyFish Search

    Find the official site

    Give it a company name and Search finds the brand’s own domain, skipping Wikipedia, social profiles and news. Paste a URL and this step is skipped.

  2. TinyFish Fetch

    Read the live pages

    Fetch reads the homepage HTML for the logo, meta tags and links, then up to nine pages such as About, Careers and Press as clean text.

  3. TinyFish Browser

    Measure the real styles

    A real browser session opens the homepage and reads the computed colours and fonts of buttons, headings, links and body text.

  4. Swatchfin

    Check every claim

    A language model drafts the tone of voice and messaging. Swatchfin keeps a quote only if it appears word for word in the fetched text.

What you get

A complete brand guide, not a homepage summary.

Swatchfin reads several pages and the rendered styles, so the guide covers the whole identity.

Logo

Found in the header, an inline SVG, the Open Graph image or the favicon, with its source and a download link.

Colour palette with roles

Primary, accent, background, text and link colours, measured from real elements. Every pair gets a WCAG contrast score.

Typography

Heading, body and UI fonts with their weights and sizes, taken from the fonts the page actually loaded.

Tone of voice

Traits, four tone scales and do and don’t lists, each backed by quotes from the site and links to where they appear.

Key messaging

Tagline, mission, value propositions and audience, each linked to the page it came from.

Verified, never invented

Every quote is checked against the fetched text. If something can’t be found, the guide says so instead of filling the gap.

Exports

Take the guide into the tools you already use.

Every guide downloads in open formats, so designers, developers and other AI tools can reuse it.

JSON

brand-guide.json

The full guide in a stable, versioned schema.

CSS

brand.css

Colours and fonts as CSS custom properties.

Tailwind

tailwind.config.js

A theme extension with the brand’s colours and fonts.

Design Tokens

tokens.json

The W3C Design Tokens format, read by tools such as Style Dictionary.

PDF

Print → Save as PDF

A clean, print-ready layout with one section per page.

Voice prompt

voice-prompt.md

A ready-to-paste prompt for writing in the brand’s voice.
